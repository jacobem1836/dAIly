# Phase 21.1: Per-User Onboarding UI — UI Spec

**Written:** 2026-05-02
**Status:** Ready for implementation
**Phase:** 21.1-per-user-onboarding-ui

---

## Overview

This spec defines every screen, state, component, and wiring needed to implement the iOS onboarding flow. The flow is a swipeable `TabView` carousel with 6 pages. The user enters it after email/magic-link auth and exits into `VoiceView` when setup is complete.

All decisions in this spec derive from `21.1-CONTEXT.md`. This document is the implementation contract — agents must not deviate without a new decision log entry.

---

## Flow Map

```
App launch
  │
  ├── hasAccessToken = false  ──→  OnboardingView (tab 0: Welcome)
  │
  └── hasAccessToken = true
        ├── hasCompletedOnboarding = false  ──→  OnboardingView (tab 0: Welcome)
        └── hasCompletedOnboarding = true   ──→  VoiceView
```

### Tab Order

| Tab index | Screen | Gate to advance |
|-----------|--------|-----------------|
| 0 | WelcomeView | None (CTA always enabled) |
| 1 | PairingView (existing) | `appState.hasAccessToken == true` |
| 2 | IntegrationView (Google) | None (Skip always available) |
| 3 | IntegrationView (Microsoft) | None (Skip always available) |
| 4 | IntegrationView (Slack) | At least one provider connected |
| 5 | ScheduleView | Save succeeds |
| 6 | CompletionView | CTA tap (no gate) |

## State Management

### AppState Changes

Add to `AppState.swift`:

```swift
@Published var hasCompletedOnboarding: Bool

init(keychain: KeychainStore = .shared) {
    self.hasAccessToken = keychain.load(key: "access_token") != nil
    self.hasCompletedOnboarding = keychain.load(key: "onboarding_complete") != nil
}
```

### New Integration State Model

```swift
// Shared across integration pages via @StateObject in OnboardingView
final class IntegrationState: ObservableObject {
    @Published var connectedProviders: Set<String> = []  // "google", "microsoft", "slack"

    var atLeastOneConnected: Bool { !connectedProviders.isEmpty }

    func markConnected(provider: String) {
        connectedProviders.insert(provider)
    }
}
```

## Root: OnboardingView

**File:** `ios/dAIly/onboarding/OnboardingView.swift`

**Purpose:** Hosts the TabView carousel. Owns the current tab index and `IntegrationState`. Blocks swipe-to-advance via `selection` binding + `onChange`.

**Props:**
- `auth: AuthService` — passed down to child views

**State:**
- `@State private var currentTab: Int = 0`
- `@StateObject private var integrationState = IntegrationState()`

**Body:**
```
TabView(selection: $currentTab) {
    WelcomeView(onContinue: { advance() })
        .tag(0)
    PairingView(auth: auth)
        .tag(1)
    IntegrationView(provider: .google, ...)
        .tag(2)
    IntegrationView(provider: .microsoft, ...)
        .tag(3)
    IntegrationView(provider: .slack, ...)
        .tag(4)
    ScheduleView(auth: auth, ...)
        .tag(5)
    CompletionView(...)
        .tag(6)
}
.tabViewStyle(.page)
.indexViewStyle(.page(backgroundDisplayMode: .always))
.onChange(of: currentTab) { newValue in
    if newValue > allowedMaxTab {
        currentTab = allowedMaxTab
    }
}
```

**Gate logic (`allowedMaxTab`):**

| Condition | Max tab allowed |
|-----------|-----------------|
| `!hasAccessToken` | 1 |
| `hasAccessToken && !atLeastOneConnected` | 4 |
| `hasAccessToken && atLeastOneConnected` | 5 |
| Schedule saved | 6 |

The `onChange` clamps `currentTab` to `allowedMaxTab` whenever the user swipes forward past a gate. Back-swipes (lower index) are always allowed.

**`advance()` helper:** increments `currentTab` by 1 if `currentTab < allowedMaxTab`.

**Deep-link handling:** `dAIlyApp.onOpenURL` extended to handle `/oauth/success?provider=` — calls `integrationState.markConnected(provider:)`. See §Deep-Link Wiring below.

## Tab 1: PairingView (existing)

**File:** `ios/dAIly/views/PairingView.swift` — **no changes**.

**Wiring:** When `appState.hasAccessToken` becomes `true` (set inside `PairingView.verifyCode()` or via the `onOpenURL` pair-code handler), `OnboardingView.allowedMaxTab` increases, enabling tab 2 advance.

The "Get started" advance from tab 0 will show the pairing flow. After the user verifies their code, `appState.hasAccessToken = true` is published — the parent `OnboardingView` observes this via `@EnvironmentObject` and updates `allowedMaxTab` accordingly. The user can then swipe or tap Continue to advance to tab 2.

**Note:** PairingView does not have an explicit "Continue" button for advancing after auth. After `hasAccessToken` flips to `true`, add a "Continue" button that appears in PairingView's `sentView` success state via a conditional driven by `appState.hasAccessToken`, OR let `OnboardingView` auto-advance to tab 2 when `hasAccessToken` becomes true. Auto-advance is preferred (less user friction).

**Implementation of auto-advance:** In `OnboardingView`, observe `appState.hasAccessToken`:
```swift
.onChange(of: appState.hasAccessToken) { newValue in
    if newValue && currentTab == 1 {
        withAnimation { currentTab = 2 }
    }
}
```

## Tabs 2–4: IntegrationView

**File:** `ios/dAIly/onboarding/IntegrationView.swift`

**Parameterised by provider.**

### Provider Enum

```swift
enum IntegrationProvider: String, CaseIterable {
    case google     = "google"
    case microsoft  = "microsoft"
    case slack      = "slack"

    var displayName: String {
        switch self {
        case .google:    return "Google"
        case .microsoft: return "Microsoft"
        case .slack:     return "Slack"
        }
    }

    var description: String {
        switch self {
        case .google:
            return "Access Gmail and Google Calendar to include emails and events in your briefing."
        case .microsoft:
            return "Access Outlook and Microsoft Teams to include emails and meeting summaries."
        case .slack:
            return "Access your Slack channels and DMs for message highlights."
        }
    }

    var icon: String {
        switch self {
        case .google:    return "envelope.circle.fill"
        case .microsoft: return "calendar.circle.fill"
        case .slack:     return "bubble.left.and.bubble.right.fill"
        }
    }
}
```

### Props

- `provider: IntegrationProvider`
- `auth: AuthService`
- `integrationState: IntegrationState` (passed as `@ObservedObject`)
- `onContinue: () -> Void`
- `isLastIntegrationPage: Bool` — true for Slack (tab 4), controls Skip button visibility

### State

- `@State private var isConnecting: Bool = false`
- `@State private var errorMessage: String? = nil`

**Computed:**
- `isConnected: Bool` — `integrationState.connectedProviders.contains(provider.rawValue)`
- `canSkip: Bool` — `!isLastIntegrationPage || integrationState.atLeastOneConnected`

### Layout

```
VStack(spacing: 24) {
    Spacer()

    Image(systemName: provider.icon)
        .font(.system(size: 56))
        .foregroundStyle(.primary)

    Text("Connect \(provider.displayName)")
        .font(.title2)
        .fontWeight(.semibold)

    Text(provider.description)
        .font(.body)
        .foregroundStyle(.secondary)
        .multilineTextAlignment(.center)
        .padding(.horizontal)

    if isConnected {
        // Connected state
        HStack(spacing: 8) {
            Image(systemName: "checkmark.circle.fill")
                .foregroundStyle(.green)
            Text("Connected")
                .foregroundStyle(.secondary)
        }
        .font(.body)

        Button("Continue") { onContinue() }
            .buttonStyle(.borderedProminent)
            .controlSize(.large)

    } else {
        // Not yet connected
        if let error = errorMessage {
            Text(error)
                .foregroundStyle(.red)
                .font(.caption)
        }

        Button(isConnecting ? "Connecting…" : "Connect \(provider.displayName)") {
            Task { await connectProvider() }
        }
        .buttonStyle(.borderedProminent)
        .controlSize(.large)
        .disabled(isConnecting)

        if canSkip {
            Button("Skip") { onContinue() }
                .buttonStyle(.borderless)
                .foregroundStyle(.secondary)
        }
    }

    Spacer()
}
.padding()
```

### OAuth Connect Logic

```swift
private func connectProvider() async {
    isConnecting = true
    errorMessage = nil
    do {
        let authURL = try await auth.getIntegrationConnectURL(provider: provider.rawValue)
        // Open ASWebAuthenticationSession — success delivered via onOpenURL deep link
        // Session stays open; integrationState updated when /oauth/success arrives
        try await auth.openOAuthSession(url: authURL, provider: provider.rawValue)
    } catch {
        errorMessage = "Connection failed. Please try again."
    }
    isConnecting = false
}
```

**Note:** `openOAuthSession` uses `ASWebAuthenticationSession`. The session completes when the Universal Link `/oauth/success?provider={provider}` is received. `dAIlyApp.onOpenURL` calls `integrationState.markConnected(provider:)` and the view updates reactively.

### Save Logic

```swift
private func saveSchedule() async {
    isSaving = true
    errorMessage = nil
    let timeZone = TimeZone.current.identifier
    let formatter = DateFormatter()
    formatter.dateFormat = "HH:mm"
    let timeString = formatter.string(from: briefingTime)
    do {
        try await auth.savePreferences(briefingTime: timeString, timezone: timeZone)
        KeychainStore.shared.save(key: "onboarding_complete", value: "true")
        onComplete()
    } catch {
        errorMessage = "Failed to save. Please try again."
        isSaving = false
    }
}
```

## AuthService Extensions

Add to `ios/dAIly/auth/AuthService.swift`:

### Get Integration Connect URL

```swift
/// Fetches the OAuth authorization URL for the given provider.
/// Calls GET /integrations/{provider}/connect with Bearer token.
public func getIntegrationConnectURL(provider: String) async throws -> URL {
    // GET /integrations/{provider}/connect
    // Returns { "authorization_url": "https://..." }
    struct Resp: Decodable { let authorization_url: String }
    let resp: Resp = try await getJSON(
        path: "/integrations/\(provider)/connect",
        expecting: Resp.self
    )
    guard let url = URL(string: resp.authorization_url) else {
        throw AuthError.decoding
    }
    return url
}
```

### Open OAuth Session

```swift
/// Opens ASWebAuthenticationSession for the given URL.
/// Resolves when the session completes or is cancelled.
/// The actual success signal comes via onOpenURL deep link, not the session callback.
@MainActor
public func openOAuthSession(url: URL, provider: String) async throws {
    // Implementation uses ASWebAuthenticationSession
    // Callback scheme: universal link — session is dismissed on redirect
    // No token is passed back through the redirect URL (SEC-01 compliance)
    // onOpenURL in dAIlyApp handles /oauth/success?provider= to update state
    try await withCheckedThrowingContinuation { continuation in
        let session = ASWebAuthenticationSession(
            url: url,
            callbackURLScheme: nil  // Universal Links, not custom scheme
        ) { _, error in
            if let error { continuation.resume(throwing: error) }
            else { continuation.resume() }
        }
        session.presentationContextProvider = /* window scene provider */
        session.prefersEphemeralWebBrowserSession = false
        session.start()
    }
}
```

### Save Preferences

```swift
/// Saves briefing time and timezone to the backend.
/// Calls PUT /users/preferences with Bearer token.
public func savePreferences(briefingTime: String, timezone: String) async throws {
    try await putJSON(
        path: "/users/preferences",
        body: ["briefing_time": briefingTime, "timezone": timezone],
        expecting: EmptyResponse.self
    )
}
```

Add a private `getJSON` and `putJSON` helper following the same pattern as the existing `postJSON`.

## dAIlyApp.swift Changes

### Root Routing

```swift
Group {
    if appState.hasAccessToken && appState.hasCompletedOnboarding {
        VoiceView(session: VoiceSession(...))
    } else {
        OnboardingView(auth: auth)
    }
}
```

### onOpenURL Extension

```swift
.onOpenURL { url in
    // Pair code handling (existing)
    if let code = PairCodeURLParser.extractPairCode(from: url) {
        Task { @MainActor in
            do {
                _ = try await auth.completePairing(code: code)
                appState.hasAccessToken = true
            } catch {
                print("[dAIly] pair complete failed: \(error)")
            }
        }
        return
    }

    // OAuth success deep link (new)
    // URL shape: dailyapp://oauth/success?provider=google (or Universal Link equivalent)
    if let components = URLComponents(url: url, resolvingAgainstBaseURL: false),
       components.path.hasSuffix("/oauth/success"),
       let provider = components.queryItems?.first(where: { $0.name == "provider" })?.value {
        Task { @MainActor in
            integrationState.markConnected(provider: provider)
        }
    }
}
```

**Note:** `integrationState` must be accessible from `dAIlyApp`. The cleanest approach is to lift `IntegrationState` into `AppState` or pass it as an `EnvironmentObject` from `dAIlyApp` down through `OnboardingView`. Preferred: expose `integrationState` as an `@StateObject` in `dAIlyApp` and inject it via `.environmentObject(integrationState)`.

## Deep-Link Wiring

The Universal Link for OAuth success must be registered. Based on Phase 19 patterns:
- Path: `/oauth/success`
- Query: `?provider={google|microsoft|slack}`

The `PairCodeURLParser` pattern can be extended — or a new `OAuthCallbackParser` added alongside it.

**Existing** `onOpenURL` in `dAIlyApp` already handles pair codes. The new handler branches on path suffix `/oauth/success`.
