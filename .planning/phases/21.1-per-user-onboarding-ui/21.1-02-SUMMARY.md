# Phase 21.1 Plan 02: AuthService OAuth Methods Summary

**One-liner:** Bearer-authenticated getIntegrationConnectURL + savePreferences + fire-and-forget openOAuthSession with ASWebAuthenticationSession, backed by 6 new request-capturing stub tests.

## What Was Built

### Task 1: getJSON/putJSON helpers + getIntegrationConnectURL + savePreferences (commit 606d517)

Added three private helpers to `AuthService`:
- `sendAndDecode<T>` — shared HTTP response decoding/error mapping (extracted from postJSON to eliminate duplication)
- `getJSON<T>` — builds GET request, injects `Authorization: Bearer {access_token}` from Keychain
- `putJSON<T>` — builds PUT request with JSON body, injects Bearer header

Added two public methods:
- `getIntegrationConnectURL(provider:)` — calls `GET /integrations/{provider}/connect`, decodes `{ "auth_url": "..." }` (field name pinned in tests)
- `savePreferences(briefingTime:timezone:)` — calls `PUT /users/me/preferences` (path pinned in tests, not `/users/preferences`)

Extended `StubURLProtocol` with `capturedRequests: [URLRequest]` array for header/method/path verification.

Added 6 new tests to `AuthServiceTests`:
1. `testGetIntegrationConnectURLParsesAuthUrl` — verifies auth_url field decoding
2. `testGetIntegrationConnectURLSendsBearerHeader` — verifies Authorization header, path suffix, method
3. `testGetIntegrationConnectURLUnauthorized` — 401 → AuthError.unauthorized
4. `testGetIntegrationConnectURLDecodingError` — wrong JSON field → AuthError.decoding
5. `testSavePreferencesSucceedsOn204` — 204 success, PUT method, correct path, Bearer + Content-Type headers
6. `testSavePreferencesSendsBodyFields` — body contains briefing_time and timezone (reads httpBodyStream fallback)

### Task 2: openOAuthSession + OAuthPresentationContextProvider (commit 32f80d8)

Added `openOAuthSession(url:)` to `AuthService`:
- Creates `ASWebAuthenticationSession` with `callbackURLScheme: nil` (Universal Link pattern)
- Assigns `OAuthPresentationContextProvider` as context provider
- Sets `prefersEphemeralWebBrowserSession = false` (preserves existing browser session)
- Stores session in `currentOAuthSession` to keep it alive
- Throws `AuthError.network` if `session.start()` returns false
- No `withCheckedThrowingContinuation` (Pitfall 4 avoided)

Added `OAuthPresentationContextProvider: NSObject, ASWebAuthenticationPresentationContextProviding`:
- Traverses `connectedScenes` to find foreground-active `UIWindowScene`
- Returns `keyWindow` → `windows.first` → `UIWindow()` fallback chain
- Required for pure SwiftUI lifecycle (no SceneDelegate)
