### Notable Deviations from Plan Spec (Non-blocking)

1. **callbackURLScheme: "daily" instead of nil** — Plan 02 spec required `callbackURLScheme: nil` for Universal Links. Actual implementation uses `callbackURLScheme: "daily"` with a custom URL scheme registered in Info.plist (`CFBundleURLSchemes: ["daily"]`). This is correct: the backend redirects to `daily://oauth/success?provider=` (verified in `src/daily/integrations/router.py` lines 225, 325, 417), not to a Universal Link HTTPS URL. The plan spec was written against an incorrect assumption about the backend redirect shape.

2. **OAuthCallbackParser path matching** — Actual parser adds `|| comps.path == "/success"` alongside `hasSuffix("/oauth/success")`. This is required because for `daily://oauth/success?provider=google`, URLComponents parses `"oauth"` as the host and `"/success"` as the path. The `hasSuffix` handles HTTPS Universal Link URLs; the `== "/success"` handles the custom scheme URL.

3. **NotificationCenter bridge in dAIlyApp** — An additional `.onReceive(NotificationCenter.default.publisher(for: .oauthCallbackReceived))` handler is wired in dAIlyApp to handle the OAuth callback from ASWebAuthenticationSession's completion closure (which fires on the non-main thread). The completion closure posts a notification; dAIlyApp dispatches to `handleDeepLink`. This is required because ASWebAuthenticationSession's completion handler fires for `callbackURLScheme:` callbacks — the plan's fire-and-forget model assumed Universal Links (where the completion never fires).

4. **Single-argument .onChange** — All `.onChange` calls use the single-argument form for iOS 16 deployment target compatibility. The plan spec used the two-argument iOS 17+ form.

5. **PairingView gained onComplete callback** — The existing `PairingView` was updated to accept `onComplete: @escaping () -> Void`, called after successful pairing. This was needed for OnboardingView to advance the carousel programmatically.

All deviations are cohesive and correct; they represent adaptations to the actual backend contract and iOS deployment target constraints.
