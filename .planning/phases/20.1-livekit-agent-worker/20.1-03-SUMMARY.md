# Phase 20.1 Plan 03: Full Voice Loop Entrypoint Summary

**One-liner:** `DailyAgentLLM` LLM adapter + `build_voice_pipeline()` factory wires deepgram STT / cartesia TTS / silero VAD to the LangGraph bridge; `agent.py` entrypoint replaces its stub with the full connect → load-session → speak-briefing → voice-loop pattern using `VoicePipelineAgent` (livekit-agents 0.12.x API).

## What Was Built

### Task 1: voice_pipeline.py — VoicePipelineAgent factory + LLM adapter

`src/daily/worker/voice_pipeline.py`:
- `DailyAgentLLM(agents_llm.LLM)` — adapter subclass; `chat()` extracts the last `user`-role message from `ChatContext` and returns a `_DailyLLMStream` that routes to `DailyLLMBridge.stream_response()`
- `_DailyLLMStream(agents_llm.LLMStream)` — `_run()` iterates bridge deltas and pushes `ChatChunk` objects through the LiveKit internal channel
- `build_voice_pipeline(bridge, settings) -> VoicePipelineAgent` — wires deepgram STT (nova-3), cartesia TTS (sonic-2, project voice ID), silero VAD, DailyAgentLLM

`tests/test_worker_voice_pipeline.py` — 4 tests (all pass):
- `test_chat_extracts_last_user_message` — verifies the last user turn is selected from a multi-turn context
- `test_chat_extracts_only_user_message_when_single` — single user message path
- `test_chat_returns_empty_string_when_no_user_message` — graceful empty fallback
- `test_build_voice_pipeline_returns_voice_pipeline_agent` — verifies STT/TTS/VAD/LLM wiring with monkeypatched constructors

### Task 2: agent.py — full voice loop entrypoint

`src/daily/worker/agent.py` (replaced stub from 20.1-01):
1. `ctx.connect()` — connects to the LiveKit room
2. `parse_user_id_from_room(ctx.room.name)` — extracts user_id; shuts down on invalid room
3. `asyncio.wait_for(ctx.wait_for_participant(), 300)` — waits for mobile client with 5-min timeout (T-20.1-08)
4. `async with load_user_session_state(user_id, settings) as bundle` — loads graph + briefing
5. `DailyLLMBridge(graph, config, initial_state)` — wires LangGraph to the voice LLM
6. `agent = build_voice_pipeline(bridge, settings)` — assembles VoicePipelineAgent
7. `agent.start(ctx.room)` — synchronous start (0.12.x API)
8. `await (await agent.say(briefing, allow_interruptions=True)).join()` — speaks briefing; falls back to "no briefing cached" message when empty
9. `asyncio.Event()` + `ctx.add_shutdown_callback(_on_shutdown)` — blocks until room ends

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] livekit-agents 0.12.x API mismatch — AgentSession does not exist**
- **Found during:** Task 1 implementation
- **Issue:** Plan was authored assuming `AgentSession` / `Agent` from livekit-agents 1.0+. The installed version is `0.12.21` which uses `VoicePipelineAgent` instead. `AgentSession` does not exist in 0.12.x.
- **Fix:** Used `VoicePipelineAgent` from `livekit.agents.pipeline`; removed `Agent(instructions=...)` wrapper; passed `chat_ctx` with system message instead; `start()` is synchronous (not `await`); `say()` returns a `SpeechHandle` that needs `.join()` to block
- **Files modified:** `src/daily/worker/voice_pipeline.py`, `src/daily/worker/agent.py`
- **Commits:** c1eb91c, 38b94a0

**2. [Rule 2 - Missing] LLMStream constructor requires asyncio event loop in tests**
- **Found during:** Task 1 test execution
- **Issue:** `_DailyLLMStream.__init__` calls `super().__init__()` which calls `asyncio.create_task()` — this fails in synchronous test context (RuntimeError: no running event loop)
- **Fix:** Tests mock `_DailyLLMStream` with a lightweight capturing class that records `_user_msg` without triggering task creation; tests that needed it were made `@pytest.mark.asyncio`
- **Files modified:** `tests/test_worker_voice_pipeline.py`
- **Commits:** c1eb91c

**3. [Rule 2 - Missing] add_shutdown_callback requires async coroutine function, not lambda**
- **Found during:** Task 2 implementation
- **Issue:** `JobContext.add_shutdown_callback` type annotation requires `Callable[[], Coroutine]` — a plain lambda is not valid
- **Fix:** Defined `async def _on_shutdown() -> None: done_event.set()` inside the entrypoint
- **Files modified:** `src/daily/worker/agent.py`
- **Commits:** 38b94a0
