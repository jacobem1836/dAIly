## Summary

Containerized the LiveKit agent worker and wired it into both dev and prod compose stacks. Worker builds cleanly, registers with the LiveKit server on startup, and serves voice sessions to real mobile clients.

## What Was Built

- `Dockerfile.worker` — Python 3.11-slim image with ffmpeg, uv, Silero VAD pre-download, and `python -m daily.worker` entrypoint
- `docker-compose.yml` — worker service added (dev mode, source volume-mounted for hot reload, depends on postgres/redis/livekit)
- `docker-compose.prod.yml` — worker service added (prod mode, `restart: unless-stopped`, no bind mount)
- `20.1-SMOKE-TEST.md` — end-to-end smoke test runbook

## Verification

- `docker compose config -q` exits 0 ✓
- Worker container logs show `registered worker` within 15s of compose up ✓
- iOS client connected, heard briefing audio, completed voice turns ✓

## Deviations

None from plan tasks 1–2. Task 3 (smoke test) was run in the same session — iOS only (Android not tested). Auth bug (`vault_key.encode()` → `base64.b64decode(vault_key)`) and user deduplication (email column on users table) were discovered and fixed during smoke test.
