# Phase 20.1 Plan 02: Worker Orchestrator Integration Layer Summary

**One-liner:** `load_user_session_state` async context manager bundles graph + LangGraph config + Redis briefing cache into a `SessionBundle`; `DailyLLMBridge` translates `stream_response(text)` calls into `astream_session`/`run_session` invocations — both tested in isolation with 6 passing tests.

## What Was Built

### Task 1: load_user_session_state (TDD)

`src/daily/worker/state.py`:
- `SessionBundle` dataclass: `graph`, `config`, `initial_state`, `briefing_narrative`
- `load_user_session_state(user_id, settings?)` — async context manager that:
  1. Resolves email adapters via `_resolve_email_adapters` and registers them via `set_email_adapters`
  2. Opens `AsyncPostgresSaver` and calls `checkpointer.setup()` (idempotent)
  3. Calls `build_graph(checkpointer=checkpointer)`
  4. Calls `create_session_config(user_id)` — thread_id format: `user-{id}-YYYY-MM-DD`
  5. Opens Redis, calls `initialize_session_state`, closes Redis in `finally`
  6. Yields `SessionBundle`; `AsyncPostgresSaver` closes on exit

`tests/test_worker_state.py` — 3 tests (all pass):
- `test_session_bundle_populated` — bundle fields all present and correct
- `test_thread_id_format` — thread_id matches `user-1-YYYY-MM-DD` regex
- `test_briefing_empty_on_cache_miss` — empty briefing_narrative when state has `""`

### Task 2: DailyLLMBridge (TDD)

`src/daily/worker/llm_bridge.py`:
- `DailyLLMBridge(graph, config, initial_state)` — adapter class
- `async def stream_response(user_input) -> AsyncIterator[str]`:
  - First call: passes `initial_state` to `astream_session`; sets `_first_turn = False` in `finally`
  - Subsequent calls: passes `None` as initial_state
  - On `StreamingNotSupported`: falls back to `run_session`, yields `last_message.content` as single chunk
  - Exit/quit handling belongs to the caller (LiveKit agent entrypoint)

`tests/test_worker_llm_bridge.py` — 3 tests (all pass):
- `test_streams_tokens` — yields ["Hello", " ", "world"] from stubbed astream_session
- `test_fallback_on_streaming_not_supported` — yields ["fallback content"] from run_session result
- `test_initial_state_only_on_first_turn` — first call gets initial_state, second call gets None
