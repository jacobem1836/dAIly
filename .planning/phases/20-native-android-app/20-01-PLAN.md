```python
@app.get("/.well-known/assetlinks.json", include_in_schema=False)
async def asset_links() -> JSONResponse:
    """Serve Android App Links assetlinks.json (Phase 20 / MOB-02).

    Android verifies App Links at install time by fetching this file and
    matching the SHA-256 fingerprint(s) against the installed APK's signing
    certificate. Multiple fingerprints (debug + release) supported via
    comma-separated env var.
    """
    settings = Settings()
    fingerprints = [
        fp.strip()
        for fp in settings.android_sha256_fingerprint.split(",")
        if fp.strip()
    ]
    return JSONResponse(
        content=[
            {
                "relation": ["delegate_permission/common.handle_all_urls"],
                "target": {
                    "namespace": "android_app",
                    "package_name": settings.android_package_name,
                    "sha256_cert_fingerprints": fingerprints,
                },
            }
        ],
        media_type="application/json",
    )
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Internet → FastAPI | Anonymous public GET; Android verification service fetches at install time |
| Settings → Response body | Env-controlled values (package_name, sha256) flow into a public JSON document |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-20-01 | Spoofing | assetlinks.json contents | mitigate | SHA-256 fingerprint sourced ONLY from env Settings; never user-controlled. Wrong fingerprint → app links fail closed (browser fallback), not silent compromise. |
| T-20-02 | Tampering | Response transformation | mitigate | No request input is reflected in the response; response is fully determined by Settings. No path/query/body params consumed by the route. |
| T-20-03 | Information Disclosure | Hidden endpoint enumeration | accept | The response is intentionally public per Google Digital Asset Links spec. No PII; package name + fingerprint are not secrets. |
| T-20-04 | Denial of Service | Anonymous public GET | accept | Trivial JSON serialization; same surface as the existing AASA endpoint which has been live since plan 19-01 without abuse. |
</threat_model>
