**Task 2 – Runbook created:**
`docs/runbook/livekit-worker.md` — five diagnostic steps:
1. Confirm worker process is running (`ps aux`)
2. Confirm LIVEKIT_URL / API_KEY / API_SECRET in `.env`

4. Verify `/livekit/token` returns the correct URL
5. Watch worker logs for `room subscribed` / `agent joined`
