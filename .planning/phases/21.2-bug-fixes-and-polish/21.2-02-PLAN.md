<objective>
D-02 + D-06: Make the magic-link email actually open the app, and stop Google's "unverified app" interstitial from blocking new test users.

D-02 root cause per CONTEXT.md: APPLE_TEAM_ID is missing/empty in `.env`, so the AASA `appID` field renders as `.<bundle_id>` — invalid, so Apple's CDN refuses to associate the domain with the app. Universal Links silently fail. Adding APPLE_TEAM_ID + verifying entitlements + verifying the AASA response fixes routing.

D-06: Google's "App not verified" screen appears for any account not on the test-users list. Fix for now is to add testers in Google Cloud Console; production fix (Google verification submission) is documented as a launch blocker, not a code change.

Output: APPLE_TEAM_ID configured, AASA verified live, entitlements aligned, Google test users documented.
</objective>
