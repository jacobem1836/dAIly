# Phase 21.2 Plan 01: On-Demand Briefing Trigger + Multi-Provider Adapter Audit Summary

**One-liner:** POST /briefings/trigger endpoint with iOS spinner gating onboarding completion, reusing scheduler adapter resolution for immediate first-briefing generation.

## What Was Built

### Task 1 -- POST /briefings/trigger Endpoint (D-04)

Created `src/daily/briefing/router.py` with an authenticated FastAPI endpoint that:
- Requires Bearer JWT via `Depends(get_current_user)`
- Calls `_build_pipeline_kwargs` from `scheduler.py` to resolve all adapters (Google, Outlook, Slack), Redis, and OpenAI client identically to the cron-scheduled run
- Runs `run_briefing_pipeline` synchronously (blocking) -- iOS client shows spinner while waiting
- Returns `202 {"status": "completed"}` on success
- Returns `500 {"detail": "briefing_generation_failed"}` on pipeline error with no token data leaked
- Closes Redis connection in `finally` block to prevent leaks

Wired into `src/daily/main.py` as `app.include_router(briefing_router)`.

Test coverage: 4 tests (auth, unauth, pipeline call verification, sanitised error response).

### Task 2 -- Multi-Adapter Warning + iOS Trigger (D-03, D-04)

**Backend audit (D-03):**

Confirmed `scheduler.py` correctly appends Outlook tokens to `email_adapters` (line 113) and Slack tokens to `message_adapters` (line 117). Confirmed `context_builder.py` iterates ALL adapters in `_fetch_all_emails` and `_fetch_all_messages`.

Added warning log to `context_builder.py` when `len(email_adapters) > 1` to surface the M2 body-routing limitation without changing functional behavior. The email list phase already loads all adapters correctly -- only the body fetch step is limited to `adapters[0]`.

**iOS (D-04):**

- `AuthService.swift`: added `triggerBriefing()` public method calling `POST /briefings/trigger` with Bearer auth and 60s timeout
- `CompletionView.swift`: added `auth: AuthService` property, `@State isGeneratingBriefing`, `@State briefingError`; button tap now runs `auth.triggerBriefing()` in an async Task, shows `ProgressView("Generating your first briefing...")` while in progress, calls `onFinish()` on success, shows red error text with retry prompt on failure
- `OnboardingView.swift`: passes `auth: auth` through to `CompletionView`
