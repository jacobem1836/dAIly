# 21.2-04 Summary: iOS UX polish (D-05, D-07, D-08, D-09)

## What was done

### D-05 – OTP keypad auto-dismissal (PairingView.swift)
Added `.onChange(of: code)` modifier on the 6-digit code TextField. When `code.count == 6`, calls `UIApplication.shared.sendAction(#selector(UIResponder.resignFirstResponder), ...)` to dismiss the numeric keypad. Single-argument `onChange` form for iOS 16 compat.

### D-08 – 'magic link' → 'link' copy (PairingView.swift)
- `Button("Send magic link")` → `Button("Send link")`
- `"We sent a magic link to \(email)."` → `"We sent a link to \(email)."`
Internal comments and variable names untouched.

### D-07 – Page-indicator dot overlap (all onboarding slides)
Added `.padding(.bottom, 40)` to the outer VStack in all 5 affected files:
- `WelcomeView.swift`
- `IntegrationView.swift`
- `ScheduleView.swift`
- `CompletionView.swift`
- `PairingView.swift`
- `PermissionsView.swift` (included preemptively as it's also inside the TabView)

### D-09 – Microphone permissions onboarding step
**Created `ios/dAIly/onboarding/PermissionsView.swift`:**
- Shows mic icon, explanation, and "Allow microphone" button
- On tap: calls `AVAudioSession.sharedInstance().requestRecordPermission` (iOS 16 compat)
- On grant: calls `onGranted()` to advance the TabView
- On denial: shows "Open Settings" button; re-reads permission on `.onAppear` (user may return from Settings)
- Includes `.padding(.bottom, 40)` for D-07

**Updated `ios/dAIly/onboarding/OnboardingView.swift`:**
- Added `import AVFoundation`
- Added `@State private var micPermissionGranted: Bool = false`
- Inserted PermissionsView as `.tag(5)` between Slack and Schedule
- Renumbered Schedule `.tag(5)` → `.tag(6)`, Completion `.tag(6)` → `.tag(7)`
- `allowedMaxTab` updated: `if !micPermissionGranted { return 5 }` gate added; schedule gate → `return 6`; completion → `return 7`
- `.task` now also reads `AVAudioSession.sharedInstance().recordPermission` on appear to pre-grant for returning users

**Ran `xcodegen`** to register PermissionsView.swift in the Xcode project (sources: [dAIly] is a directory glob, not a file list — xcodegen regeneration required).
