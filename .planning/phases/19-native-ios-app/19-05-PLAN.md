| Boundary | Description |
|----------|-------------|
| Tunnel host ↔ backend | Trusted dev-only path; production uses VPS HTTPS termination |
| Physical device ↔ LiveKit dev server | TLS WSS (LiveKit refuses unencrypted production tokens) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-19-25 | Tampering | Backend URL accidentally pointing to attacker-controlled host | mitigate | `Config.backendBaseURL` is the only place the URL is set; reviewers can audit a single line. Acceptance criteria forbids duplicate URL literals (Task 1). |
| T-19-26 | Information Disclosure | Tunnel URL leakage | accept | Dev-only artifact; tunnel rotates. Production replaces with locked VPS host before TestFlight. |
| T-19-27 | Spoofing | Universal Link with attacker-supplied code | mitigate | Backend `/auth/pair/complete` enforces single-use 5-min TTL (Phase 18). PairCodeURLParser strict path/query check (Plan 03 T-19-12). |
| T-19-28 | DoS | Reconnect storm | mitigate | 30-second reconnect timeout (Task 1) → user-visible error → user-initiated retry. No automatic indefinite retry. |
| T-19-29 | Information Disclosure | Audio captured outside intended session | mitigate | Manual test #6 verifies disconnect deactivates audio session. SDK behavior verified by checking that mic indicator clears in iOS status bar after End. |
</threat_model>
