       @router.post("/pair/send-link", status_code=204)
       async def pair_send_link(
           req: SendLinkRequest,
           db: AsyncSession = Depends(_get_db),
           settings: Settings = Depends(_get_settings),

           code = generate_pairing_code()

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → /auth/pair/send-link | Untrusted email submission crosses HTTPS boundary |
| /auth/pair/send-link → Resend API | Backend-to-third-party SaaS over HTTPS (API key in env) |
| Apple CDN → /.well-known/apple-app-site-association | Public, unauthenticated read |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-19-01 | Information Disclosure | POST /auth/pair/send-link | mitigate | Always return 204 — never confirm whether the email is registered. ResendError is logged server-side but NOT surfaced. (Task 2 test 4) |
| T-19-02 | Spoofing | Magic link delivery | mitigate | Pair codes are single-use, 5-min TTL (existing), and delivered only via the verified `magic_link_base_url`. HTTPS Universal Link cannot be hijacked by another app (D-03). |
| T-19-03 | Information Disclosure | Resend API key | mitigate | Stored only in backend `.env` (`RESEND_API_KEY`); never logged, never returned in responses, never bundled with iOS app (D-04). |
| T-19-04 | Tampering | AASA endpoint | mitigate | Served over HTTPS only via existing FastAPI HTTPS termination; no redirects (Apple CDN rejects); content fully derived from server-side env, no user input. |
| T-19-05 | Denial of Service | POST /auth/pair/send-link | accept | Existing FastAPI rate-limiting middleware (Phase 14/15) covers this; no new endpoint-specific limit needed for v1.4. Revisit if abuse observed. |
| T-19-06 | Elevation of Privilege | Pair code generation | mitigate | Reuses existing `generate_pairing_code` (cryptographically random per Phase 18 audit). No new code path. |
</threat_model>
