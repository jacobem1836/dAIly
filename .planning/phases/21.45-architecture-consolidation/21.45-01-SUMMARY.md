## Checkpointer Decision (Task 3)

Decision: **kept `_run_chat_session` on AsyncPostgresSaver** (option a).

Wiring AsyncPostgresSaver into the CLI dev harness required wrapping the interactive loop in an `async with AsyncPostgresSaver.from_conn_string(settings.database_url_psycopg) as checkpointer:` block -- 3 additional lines, identical pattern to `worker/state.py`. This was trivially cheap so the harness was kept.

Also updated docstring references to MemorySaver in `orchestrator/graph.py` and `orchestrator/session.py` -- they described the old Phase 3 pattern.

`grep -rn "MemorySaver" src/daily/ --include="*.py"` now returns zero matches.
