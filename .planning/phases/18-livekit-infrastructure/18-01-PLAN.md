```python
"""Smoke tests for LiveKit infrastructure (Phase 18, INFRA-01)."""
import httpx
import pytest
from livekit.api import AccessToken, VideoGrants


def test_livekit_dev_container_reachable():
    """LiveKit dev container responds on localhost:7880. Skips if not running."""
    try:
        resp = httpx.get("http://localhost:7880", timeout=2.0)
    except (httpx.ConnectError, httpx.ConnectTimeout):
        pytest.skip("LiveKit dev container not running (docker compose up)")
    # LiveKit returns 404 on root HTTP GET — confirms the server is responding
    assert resp.status_code in (200, 404), f"Unexpected status {resp.status_code}"


def test_livekit_access_token_signs():
    """livekit-api SDK can mint a JWT with the dev key/secret."""
    token = (
        AccessToken("devkey", "secret")
        .with_identity("test-user")
        .with_grants(VideoGrants(room_join=True, room="test-room"))
        .to_jwt()
    )
    assert isinstance(token, str)
    assert len(token) > 50  # JWTs are long
    assert token.count(".") == 2  # JWT format: header.payload.signature
```

Do NOT mock `AccessToken` — this test verifies the SDK is installed and functional.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host → LiveKit container | LiveKit binds 7880/7881 in dev; in prod uses `network_mode: host` with TURN on UDP 3478 / TCP 443/5349 |
| Coturn → public internet | TURN relay accepts external UDP packets; gated by `static-auth-secret` HMAC |
| FastAPI process → environment | LiveKit API key/secret loaded from env vars only; never logged or hardcoded |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-01 | Information Disclosure | LiveKit API key/secret | mitigate | Stored in env vars (`LIVEKIT_API_KEY`, `LIVEKIT_API_SECRET`); `.env.example` ships with dev placeholders only; production values supplied at deploy time and never committed |
| T-18-02 | Tampering | Coturn open-relay abuse | mitigate | `lt-cred-mech` + `use-auth-secret` + `static-auth-secret` in `turnserver.conf`; only LiveKit knows the TURN secret per RESEARCH.md Pitfall 5 |
| T-18-03 | Spoofing | LiveKit ICE candidate spoofing on VPS | mitigate | `use_external_ip: true` in `livekit.yaml` ensures candidates advertise correct public IP per RESEARCH.md Pitfall 1 |
| T-18-04 | Information Disclosure | Dev credentials reused in prod | mitigate | Production `livekit.yaml` keys block contains `REPLACE_API_KEY: REPLACE_API_SECRET` placeholder forcing operator action; production compose does NOT use `--dev` flag |
| T-18-05 | Denial of Service | Public LiveKit endpoint flooded | accept | Single-VPS scale (~50 sessions per D-07) is below DoS threshold for indie deployment; document scale-out trigger; revisit when traffic justifies WAF/rate-limit |
</threat_model>
