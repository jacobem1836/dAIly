# 21.3-01 Plan: Visual Polish

## Goal
Visual polish pass across all iOS screens — consistency in spacing, typography,
colours, and interaction states. App looks intentional and production-ready before
TestFlight, not like a prototype.

## Scope

### 1. ConnectionIndicator — main screen centrepiece
- Circle 72px → 96px
- Idle colour: `Color.accentColor.opacity(0.6)` (on-brand) vs grey system placeholder
- Move pulse ring out of `.overlay` into a `ZStack` with the main circle
- Add faint ambient outer ring (144px, always visible, 12% opacity) for depth
- Label: `.callout` → `.subheadline.weight(.medium)`
- Label maxWidth: 200 → 240

### 2. VoiceView — daily-use screen identity
- Add "dAIly" wordmark flush-left at top of screen in `.title3.weight(.semibold).foregroundStyle(.secondary)`

### 3. WelcomeView — first impression
- Icon: 64 → 72px, `.symbolRenderingMode(.hierarchical)`, `.foregroundStyle(.tint)`
- Body text: add `.frame(maxWidth: 300)` for consistent line wrapping

### 4. IntegrationView — onboarding icon consistency
- Icon: `.symbolRenderingMode(.hierarchical)`, `.foregroundStyle(.tint, .secondary)`
- Description text: add `.frame(maxWidth: 300)`

### 5. PermissionsView — onboarding icon consistency
- Icon: 56 → 64px, `.symbolRenderingMode(.hierarchical)`, `.foregroundStyle(.tint)`
- Body text: add `.frame(maxWidth: 300)`

### 6. ScheduleView — onboarding icon consistency
- Icon: `.symbolRenderingMode(.hierarchical)`, `.foregroundStyle(.tint)`

### 7. CompletionView — celebratory finish
- Checkmark icon: 72 → 80px, `.symbolRenderingMode(.hierarchical)` (preserves green layering)
- Summary VStack: add `.frame(maxWidth: 280)`

### 8. PairingView — sent-state icon
- `envelope.open` icon: 48 → 56px, `.symbolRenderingMode(.hierarchical)`, `.foregroundStyle(.tint)` (vs `.secondary`)

## Acceptance Criteria
- `ConnectionIndicator` has `ZStack` with 144px ambient ring + 96px main circle
- `Color.accentColor` used for idle state (not systemGray4)
- `"dAIly"` Text in `VoiceView.body`
- `.symbolRenderingMode(.hierarchical)` applied in WelcomeView, IntegrationView, PermissionsView, ScheduleView, CompletionView, PairingView
- `.foregroundStyle(.tint` in WelcomeView, IntegrationView, PermissionsView, ScheduleView
- Compilation: `xcodebuild` exits 0
