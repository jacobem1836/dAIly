# 21.3-01 Summary: Visual Polish

## What was done

### ConnectionIndicator.swift
- Replaced single-circle + overlay approach with a `ZStack` of three layers:
  1. Ambient outer ring: 144px, 12% opacity, always visible – adds depth
  2. Pulse ring: 96px stroke, animates to 1.4× scale when connecting/reconnecting
  3. Main circle: 96px fill (up from 72px)
- Idle colour changed from `Color(.systemGray4)` to `Color.accentColor.opacity(0.6)` – on-brand
- Label upgraded from `.callout` → `.subheadline.weight(.medium)`, maxWidth 200 → 240

### VoiceView.swift
